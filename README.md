# All New Server R&D

사무실의 작업자들이 브라우저에서 ComfyUI를 편집하고, Ubuntu 서버 **메인(main)** 의 GPU로 작업을 실행하는 시스템의 설계 문서입니다.

**문서 작성일: 2026-10-22 · 현재 상태: 설계 단계**

현재 저장소에는 요구사항, 프로그램 선정, 데이터 구조, 구현 절차만 포함합니다. 실행 코드, Docker 배포 파일, 서버 설치 및 서비스 실행은 아직 수행하지 않았습니다. 아래 기능은 구현 목표이며 현재 제공되는 기능이 아닙니다.

## 확정한 요구사항

- 작업자 PC는 ComfyUI 편집 화면을 담당하고 메인은 워크플로우를 실행합니다.
- 작업자는 개인 계정으로 로그인하며 접속, 작업, 모델 사용 이력을 남깁니다.
- 팀 전체가 워크플로우, 입력 자료, 생성 결과와 저장소를 공유합니다.
- 모델 선택 화면은 호환되는 로더, 텍스트 인코더, VAE, 커스텀 노드와 예제 워크플로우를 함께 안내합니다.
- 이미지·영상 생성, LLM, 텍스트 임베딩을 지원하는 실행기를 연결합니다.
- 커스텀 노드와 확장을 사용할 수 있도록 프로젝트별 실행 환경을 분리합니다.
- 여러 실행 서비스의 GPU 사용은 하나의 전역 스케줄러에서 조정합니다.
- Docker Compose로 구성하여 지원되는 다른 서버로 이전할 수 있도록 만듭니다.
- 초기 접속 범위는 사무실 내부망입니다. Docker 이식성과 외부 인터넷 공개는 별개입니다.

## 선정한 구성

| 목적 | 선정 프로그램 / 구현 방식 |
| --- | --- |
| 로그인·계정·인증 이벤트 | Keycloak, OpenID Connect |
| 사용자·모델·작업·감사 기록 | PostgreSQL |
| 서버 API·인증 세션·ComfyUI 호환 게이트웨이 | FastAPI, Authlib, SQLAlchemy, Alembic |
| GPU 작업 실행 기반 | Celery + Redis |
| GPU 전역 점유·복구·공정 배분 | PostgreSQL 상태를 사용하는 자체 GPU Dispatcher / Execution Agent |
| 이미지·영상 워크플로우 | ComfyUI + ComfyUI-Manager |
| LLM·텍스트 임베딩 | Ollama 및 모델별 추가 실행기 어댑터 |
| 모델 선택·공유 갤러리·작업 이력 화면 | React + TypeScript, ComfyUI 프런트엔드 확장 |
| 접속 주소·HTTPS·WebSocket 전달 | Caddy |
| 배포·GPU 컨테이너 연결 | Docker Engine, Compose 플러그인, NVIDIA Container Toolkit |
| 모델·입력·결과물 파일 | 메인의 영속 데이터 볼륨 |

**접속자 DB와 모델 DB 때문에 서로 다른 DB 제품을 도입할 필요는 없습니다.** PostgreSQL 한 인스턴스에 인증용 `keycloak` DB와 서비스용 `allnew` DB를 분리하고, 서비스용 DB 내부에서 사용자·모델·작업 테이블을 연결합니다. 대형 모델 파일과 영상은 파일 저장소에 두고 DB에는 경로와 메타데이터를 기록합니다.

**Celery만으로 GPU 스케줄링이 완성되지는 않습니다.** Celery는 작업 실행을 담당하고, 직접 구현하는 Dispatcher와 Execution Agent가 ComfyUI·Ollama 전체의 GPU 점유와 종료를 통제합니다. 초기 정책은 GPU 한 개에서 무거운 작업 한 개 실행입니다.

## 초기 운영 원칙

팀원이 결과물을 함께 열람·다운로드·재사용할 수 있도록 하되, 작업 실행·취소·삭제·환경 변경의 행위자는 로그인 사용자로 기록합니다. 기본 작업자 권한은 자신의 작업 취소와 실험 환경 사용이며, 전체 작업 취소·공용 환경 변경·감사 로그 조회는 관리자가 담당합니다.

ComfyUI의 원래 편집 화면을 유지합니다. 게이트웨이를 통해 HTTP, WebSocket, 업로드, 프리뷰, 커스텀 노드 통신을 연결하며 호환성은 실제 노드 조합으로 검증합니다. 임의의 Python 커스텀 노드, 운영체제 전용 노드, 외부 유료 API를 모두 자동 지원한다고 보장하지 않습니다.

공개 저장소에는 실제 IP, 계정 정보, 비밀번호, 토큰, 접속 로그, 프롬프트, 모델 가중치와 생성 결과물을 올리지 않습니다.
